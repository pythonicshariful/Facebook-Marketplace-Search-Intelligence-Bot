📖 How to Get Your Telegram Bot Token & Chat ID in 1 Minute

1️⃣ Get Bot Token (@BotFather)
  1. Open Telegram and search for @BotFather.
  2. Send /newbot and follow prompts.
  3. Choose a display name and username ending in bot.
  4. Copy the HTTP API token (e.g. 7123456789:AA...).
  5. Important: Click your new bot link and press START so Telegram allows it to message you!
2️⃣ Get Destination Chat ID
For Personal Messages:
  1. Search for @userinfobot on Telegram.
  2. Send /start.
  3. Copy the numeric Id (e.g. 1523086010).
For Groups / Channels: Add your bot to the group, send a message, and use @raw_data_bot to get the group ID (e.g. -1001928374650).
💡 Once added: Click Save Telegram Settings, then click 🔔 Send Test Notification to verify live alerts on your phone or desktop.
